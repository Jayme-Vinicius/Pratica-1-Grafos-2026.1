# Uso rápido — Parte 1

```bash
python3 main.py <arquivo_entrada> <arquivo_saida>
```

Exemplos:
```bash
python3 main.py grafo_rede_p.txt saida_parte1_p.txt
python3 main.py grafo_rede_m.txt saida_parte1_m.txt
```

O algoritmo (Dijkstra ou Bellman-Ford) é escolhido automaticamente, conforme o grafo possua ou não pesos negativos. Detalhes completos no README.md da raiz do repositório.
